## ⚡ 수파베이스(Supabase) 연동 방법 (3단계)

### 1단계: 수파베이스 프로젝트 생성
1. [Supabase 공식 사이트 (https://supabase.com)](https://supabase.com)에 로그인 후 **[New project]**를 생성합니다.

### 2단계: SQL 테이블 생성 (원클릭)
1. Supabase 대시보드 좌측 메뉴에서 **SQL Editor**로 들어갑니다.
2. 폴더 안에 생성된 **`supabase_schema.sql`** 파일의 내용을 전체 복사하여 붙여넣고, 오른쪽 아래 **[Run]** 버튼을 클릭합니다.
   - `incidents` 테이블 생성, RLS 권한 허용, 실시간 Realtime publication이 자동으로 등록됩니다.

### 3단계: 웹앱에 연결 키 입력
1. `index.html`을 브라우저에서 엽니다.
2. 상단 헤더의 **[🟡 로컬 모드 (수파베이스 설정 ⚙️)]** 버튼을 누릅니다.
3. Supabase 대시보드의 **Project Settings > API**에서 아래 두 가지를 복사해 붙여넣고 **[연결 및 저장]**을 누릅니다.
   - **Project URL** (예: `https://xxxx.supabase.co`)
   - **anon / public key** (예: `eyJhbGciOi...`)
4. 헤더가 **[🟢 수파베이스 실시간 연동됨]**으로 바뀌면 준비 완료! 🎉

> **Tip:** 코드 파일(`index.html`) 상단의 `DEFAULT_CONFIG` 변수에 URL과 Key를 직접 적어두셔도 됩니다.

## 🌟 주요 특징

### 1. 실시간 동기화 (Supabase Realtime)
- 직원이 스마트폰으로 신고서를 제출하는 즉시, 시설관리자 PC 화면에 새로고침 없이 실시간 알림 토스트와 함께 신고 내역이 등록됩니다.
- 관리자가 조치 상태(`접수` ➔ `조치중` ➔ `조치완료`)를 변경하면 모든 기기에 즉각 반영됩니다.

### 2. 안전한 오프라인/로컬 Fallback 지원
- Supabase 키가 없거나 인터넷이 불안정할 때는 브라우저 `LocalStorage` 모드로 자동 전환되어 언제나 끊김 없이 안전하게 작동합니다.

### 3. 직원용 간편 신고 (모바일 최적화)
- 10초 만에 끝나는 위치 프리셋 버튼 (`1층 로비`, `경로식당`, `2층 프로그램실` 등)
- 위험 유형 뱃지 선택
- 스마트폰 현장 사진 촬영 & 용량 최적화 자동 압축
- 음성 인식 (STT) 마이크 입력 기능

### 4. 시설관리사용 대시보드
- 통계 카드 (총 접수, 조치 대기, 조치중, 조치 완료)
- 원클릭 상태 변경 드롭다운
- 조치 결과 메모 및 조치일시 기록
- 사진 원본 확대 라이트박스
- 📥 엑셀(CSV) 다운로드 및 🖨️ 안전점검표 인쇄 모드
