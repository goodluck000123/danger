## 🌟 주요 특징

### 1. 듀얼 인터페이스 (신고자 & 시설관리사)
- **📱 직원용 간편 신고 화면 (Mobile Web 최적화)**
  - **10초 간편 접수:** 복합한 절차 없이 위치, 유형, 사진, 내용만 입력하면 즉시 접수
  - **원터치 빠른 위치 선택:** `1층 로비`, `경로식당`, `2층 프로그램실`, `엘리베이터`, `물리치료실` 등 복지관 주요 거점 프리셋 칩 제공
  - **직관적인 위험 유형 선택:** 낙상/미끄럼 ⚠️, 시설 파손 🔨, 조명/전기 💡, 소방통로 🚪, 위생 🧹 등
  - **스마트폰 사진 촬영/업로드 & 자동 최적화:** 브라우저 용량(localStorage)을 고려하여 Canvas 기반으로 자동 리사이징 및 압축
  - **음성 인식 (STT) 지원:** 스마트폰이나 PC 마이크를 통해 말로 편하게 신고 내용 작성 가능
  - **접수 완료 피드백:** 접수 고유 번호(예: `HS-2026-0929-XXXX`) 발급 및 축하 모달

- **📊 시설관리사용 대시보드 (Dashboard)**
  - **실시간 통계 현황:** 전체 접수, 조치 대기(⏳), 조치 진행중(🔧), 조치 완료(✅) 카운트 카드
  - **원클릭 상태 변경:** 리스트에서 즉시 상태를 `접수` ➔ `조치중` ➔ `조치완료` 로 업데이트
  - **상세 조치일지 기록:** 자재 수급, 수리 내역, 조치 담당자 메모 작성 및 조치일시 자동 기록
  - **사진 라이트박스 확대:** 현장 사진을 클릭하여 고화질 원본으로 확인
  - **실시간 검색 및 필터링:** 상태별 필터(조치대기/조치중/완료) 및 검색창(위치, 내용, 신고자)
  - **업무 지원 기능:**
    - 📥 **엑셀(CSV) 다운로드:** 안전점검 대장 및 보고서 제출용 파일 즉시 생성
    - 🖨️ **안전점검표 인쇄:** 불필요한 UI 요소를 숨기고 A4 출력에 최적화된 프린트 모드 지원
    - 🔄 **샘플 데이터 복구:** 복지관 실사례 기반의 샘플 데이터 즉시 로드

## 🎨 디자인 시스템 (DESIGN.md 준수)

- **Duolingo-Inspired UI System:**
  - **컬러 팔레트:** Eager Green (`#58cc02`), Storybook Green (`#d7ffb8`), Spark Blue (`#1cb0f6`), Paper White (`#ffffff`), Charcoal (`#4b4b4b`)

## 🚀 실행 방법

별도의 서버 설치나 빌드 과정 없이 바로 실행할 수 있습니다.

1. `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 사파리(Safari) 등 웹 브라우저에서 실행합니다.
2. 상단 탭에서 **[간편 신고]**와 **[관리자 보드]**를 자유롭게 전환하며 테스트해보실 수 있습니다.
3. 데이터는 사용자의 웹 브라우저 `localStorage`에 안전하게 보존되므로 새로고침해도 유지됩니다.
